# Grammar Scoring Engine

A simple grammar scoring project that takes text as input and evaluates it for grammatical correctness.

## What it does

- Takes a piece of text as input
- Checks the text for grammar-related errors
- Generates a grammar score based on the evaluation
- Can be used to compare and assess written responses

## File

`grammar_scoring_engine.ipynb` contains the complete implementation and experiments.

## How to run

Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab and run the cells from top to bottom.

## Project Status

This is currently a working project and can be extended further with better scoring methods, error categorization, and additional language features.
